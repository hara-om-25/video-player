# Відеоплеєр ХАРА ОМ

Відеоплеєр з мітками, покадровою прокруткою та регулятором.

Адреса: https://hara-om-25.github.io/video-player/

**Тут нічого не правити вручну** — цей репозиторій збирається скриптом `build.py` з репозиторію `player` (спільне джерело `src/` для аудіоплеєра, відеоплеєра й відеоредактора).
